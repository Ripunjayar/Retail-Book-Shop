# Retail Book Shop

A responsive bookstore storefront built with React and Vite. It includes a hero banner, curated book collection, category filtering, and a shopping cart summary.

## Getting started

Use a supported Node version (20.19+ or 22.12+):

```bash
npm install
npm run dev -- --host 0.0.0.0
```

## Available scripts

- `npm run dev` – start the Vite development server
- `npm run build` – create a production build
- `npm run lint` – run the project linter

## Project features

- Book categories and product filtering
- Responsive storefront layout
- Add-to-cart interactions with quantity updates
- Cart subtotal and total summary
